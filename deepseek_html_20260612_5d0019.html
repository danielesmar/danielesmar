📋 Plantilla Moderna para Classic Report (Oracle APEX)

Reporte de clientes y tarjetas con agrupación visual. Responsive, elegante, altura óptima por fila. Los datos se organizan en tarjetas: Información del cliente, datos de la tarjeta, fechas clave y motivo de rechazo. Compatible con Universal Theme.
⬇️ Uso en APEX: Copia el contenido del bloque "📦 PLANTILLA DE FILA (ROW TEMPLATE)" dentro de las propiedades del Classic Report, y añade los estilos CSS en la página o en el archivo de la aplicación.

📦 PLANTILLA DE FILA (ROW TEMPLATE) para Classic Report

Copia este código HTML en el atributo "Plantilla de fila" del Classic Report. Asegúrate de que los nombres de las columnas en # tus columnas reales # coincidan exactamente con los alias de tu consulta SQL. Los estilos CSS deben estar en la página (Inline o archivo CSS).

        </div>

    </div>
    <div class="info-grid">
        <div class="info-block">
            <div class="block-title">👥 DATOS DEL CLIENTE</div>
            <div class="data-row"><span class="data-label">Código cliente:</span><span class="data-value">#CODIGO_CLIENTE#</span></div>
            <div class="data-row"><span class="data-label">Cédula cliente:</span><span class="data-value">#CEDULA_CLIENTE#</span></div>
            <div class="data-row"><span class="data-label">Nombre cliente:</span><span class="data-value">#NOMBRE_CLIENTE#</span></div>

✔️ Nota: Para que los badges de estado tomen color, asegúrate de que en la consulta SQL el campo ESTADO contenga valores como 'aprobado', 'pendiente', 'rechazado', etc. La clase CSS se construye dinámicamente (ej: estado-aprobado). También puedes personalizar más estados en el CSS. Los nombres de columnas deben coincidir exactamente (Case sensitive se recomienda en mayúsculas o igual a tu consulta).
